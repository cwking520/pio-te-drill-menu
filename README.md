# Tight End Drill Menu — PIO Football

An interactive, mobile-friendly drill reference for tight ends. Built for self-guided summer training — every drill has a free, verified video link and coach-sourced instructions.

---

## How to Use

### Opening the Menu
1. Download `TE_Drill_Menu.html` from this repository
2. Open it in any browser (Chrome, Safari, Firefox) — **no internet required after download**, except to watch videos
3. Enter the access code when prompted
4. You're in

> Works great as a home screen shortcut on your phone. In Safari: tap Share → "Add to Home Screen." In Chrome: tap the three dots → "Add to Home Screen."

---

## Filtering & Search

- **Category filter** — tap any category chip to show only those drills
- **Setup filter** — filter by Solo, Partner, or Group (3+)
- **Search bar** — search by drill name, coach name, or equipment needed
- **Coaching Notes** — tap on any card to expand the full rep breakdown
